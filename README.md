## 📋 О проекте

**Sales Tracker Bot** — персональный Telegram-бот для владельцев бизнеса, который помогает отслеживать продажи, анализировать доходы и генерировать отчёты. Поддерживает работу с рублями и долларами с автоматической конвертацией по заданному курсу.

### Для кого этот бот?
- 👕 Продавцы одежды и аксессуаров
- 🛒 Владельцы интернет-магазинов  
- 💼 Фрилансеры и самозанятые
- 📦 Все, кто хочет вести учёт доходов

## ✨ Возможности

### 💳 Учёт сделок

| Функция | Описание |
|---------|----------|
| **Добавление сделки** | Быстрый ввод суммы с указанием валюты |
| **Мультивалютность** | Поддержка ₽ (RUB) и $ (USD) |
| **Комментарии** | Добавление заметок к каждой сделке |
| **Гибкая дата** | Указание любой даты или автоматически сегодня |
| **Удаление** | Отмена последней ошибочной сделки |

**Форматы ввода суммы:**
```
1500     → в валюте по умолчанию
1500р    → в рублях
1500₽    → в рублях  
100$     → в долларах
100д     → в долларах
```

### 📊 Статистика

Просмотр статистики за любой период с автоматической конвертацией в обе валюты.

| Период | Описание |
|--------|----------|
| 📅 Сегодня | Продажи за текущий день |
| 📅 Вчера | Продажи за вчерашний день |
| 📆 Неделя | С понедельника текущей недели |
| 📆 Месяц | С 1-го числа текущего месяца |
| 📆 Год | С 1 января текущего года |
| 🗓 Всё время | Все сделки за всю историю |
| 📅 Свой период | Выбор месяца, квартала или произвольных дат |

**Отображаемые данные:**
- Количество сделок
- Общая сумма в рублях и долларах
- Средний чек в обеих валютах
- Текущий курс конвертации

### 📈 Аналитика

#### Полная аналитика
Комплексный обзор бизнеса:
- Общая выручка за всё время
- Продажи за сегодня / неделю / месяц
- Количество сделок

#### Сравнение периодов
Сравните два любых периода и узнайте:
- 📈 Рост или 📉 падение выручки в %
- Изменение количества сделок в %

#### Динамика по месяцам
История продаж за последние 6 месяцев с разбивкой по валютам.

Визуализация данных с помощью библиотеки Matplotlib.

| Тип графика | Описание |
|-------------|----------|

### 💱 Конвертер валют

Быстрая конвертация между рублями и долларами по установленному курсу.

**Примеры конвертации:**
```
1 000 ₽  →  10.00 $
100 $    →  10 000 ₽
10 000 ₽ →  100.00 $
1 000 $  →  100 000 ₽
```

## 🚀 Установка

### Требования
- Python 3.11+
- Telegram Bot Token (от [@BotFather](https://t.me/BotFather))

### Шаг 1: Клонирование репозитория

```bash
git clone https://github.com/yourusername/sales-tracker-bot.git
cd sales-tracker-bot
```

### Шаг 2: Создание виртуального окружения

```bash
python -m venv .venv

# Windows
.venv\Scripts\activate

# Linux/macOS
source .venv/bin/activate
```

### Шаг 3: Установка зависимостей

```bash
pip install -r requirements.txt
```

### Шаг 4: Настройка конфигурации

Отредактируйте файл `config.py`:

```python
# Токен бота от @BotFather
BOT_TOKEN = "YOUR_BOT_TOKEN_HERE"

# Ваш Telegram ID (получить у @userinfobot)
ADMIN_ID = 123456789
```

### Шаг 5: Запуск бота

```bash
python bot.py
```

## 🗄 База данных

### Таблица `transactions`
| Поле | Тип | Описание |
|------|-----|----------|
| `id` | INTEGER | Уникальный идентификатор |
| `amount` | REAL | Сумма сделки |
| `currency` | TEXT | Валюта (RUB/USD) |
| `comment` | TEXT | Комментарий (опционально) |
| `created_at` | TIMESTAMP | Дата создания записи |
| `transaction_date` | DATE | Дата сделки |

### Таблица `settings`
| Поле | Тип | Описание |
|------|-----|----------|
| `key` | TEXT | Название настройки |
| `value` | TEXT | Значение |
